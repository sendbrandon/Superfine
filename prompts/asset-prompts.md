# [SERIES NAME] — Image Prompts: People, Props, Environment Plates

Companion to `series-bible.md`. Everything here is a still-image prompt for
building the reference kit. Attach the results alongside the four character
refs when generating scenes.

Conventions:

- **People** use the same three-panel lookbook layout as the four existing
  character refs (portrait, full front, full back, seamless backdrop, flat
  light) so the whole cast reads as one set. Each gets their own backdrop
  color, like the originals. 16:9.
- **Props** are single objects on a seamless backdrop, no hands, no text, no
  logos. Lit props (bulb, lava lamp, work light, candles) are shot on black
  with the object as the only light. 1:1.
- **Environment plates** are empty sets: no people, no text, no legible
  signage, labels, posters, or photos. Three-quarter angle showing two walls
  and the floor. One light source. Generate at 3:4 or 9:16, either works as
  a reference for the vertical show.
- Where a location has more than one lighting state in the show, the base
  plate is written out and the variants are one-line modifiers.
